# Before the Step

A research project website on visual attention before pedestrian crossing initiation.

## Visit the website

https://moyiwei0426.github.io/before-the-step-visual-research/

## Preview locally

Run `python -m http.server 4173` in this directory, then open http://localhost:4173/.

## Publish updates

GitHub Pages serves the root of the `main` branch. Updates pushed to `main` are published automatically.

The website includes study visualizations, selected chart data, and conceptual design illustrations. Full participant-level datasets are not included.
